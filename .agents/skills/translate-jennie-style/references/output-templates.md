# Output templates

```markdown
# Jennie Styling 一页审美地图

[research window · sample size · scene coverage]

## 一句话结论
[one precise sentence]

## 六个视觉锚点
[A compact 2-column or 3-column layout. For each characteristic: one dynamically selected sourced image, one mechanism sentence, and one transfer sentence. Use 6–8 images total.]

## 核心语法
交界 → 视觉增量 → 风格冲突 → 定调细节

[One sentence on evidence limits.]  [Optional prompt: 展开完整证据报告]
```

## C. Compact answer

When the user wants an immediate answer, compress to:

1. one style direction;
2. three evidence-based observations;
3. keep / adjust / avoid;
4. three outfit formulas;
5. one next experiment.

Do not omit why each formula reflects Jennie's styling logic.
