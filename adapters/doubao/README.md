# 豆包版使用说明

## 最短路径

1. 下载 [`JENNIE_STYLE_DECODER_DOUBAO.md`](JENNIE_STYLE_DECODER_DOUBAO.md)。
2. 打开豆包网页版或电脑客户端，新建对话。
3. 点击输入框旁的文件上传按钮，上传这个 Markdown 文件。
4. 在同一对话输入：`请完整阅读我上传的《JENNIE_STYLE_DECODER_DOUBAO.md》，把其中“给 AI 的最高优先级执行规则”作为本次任务规则。不要总结文件，直接开始 Jennie Style Decoder。`
5. 豆包应先输出一页式 Jennie 审美地图，再显示三组快速资料卡；提交资料后生成三套个性化视觉转译公式。

在 GitHub 中点击上面的文件名后，再点击文件页面右上角的 **Download raw file** 下载按钮。若按钮不方便使用，也可以下载整个仓库 ZIP，解压后只上传这一份 Markdown 文件。

## 不要上传什么

- 不需要上传整个 GitHub ZIP。
- 不需要安装 Python。
- 不需要打开 `profile-form.html`。
- 不需要理解 Codex 的 `.agents/skills` 目录。

豆包不会执行 Codex Skill 里的 Python 和 HTML，因此本目录提供的是已经改写为纯 Markdown 的单文件版本。当前 v1.1 包含 52 套精选语料的规则摘要、13 套稳定远程视觉锚点，以及本轮新增的 21 套第一方动态来源。

## 图片说明

本项目不打包 Jennie 或媒体图片。豆包版使用原始媒体的远程图片和来源页链接；若图片因网络或媒体防盗链无法显示，豆包应保留来源链接并继续给出文字分析。用户也可以在当前对话补充自己合法持有、仅用于个人分析的参考图。

## 快速验收

第一次使用时可以直接发送：

```text
请完整阅读我上传的《JENNIE_STYLE_DECODER_DOUBAO.md》，把其中“给 AI 的最高优先级执行规则”作为本次任务规则。不要总结文件，直接开始 Jennie Style Decoder。请先给我一页式审美地图，再让我填写资料；不要因为普通人身份自动降低低腰或露肤强度。
```

如果豆包只总结了附件，请重新发送上面这段启动语；不要继续在错误对话分支里填写资料。

当用户填写完资料后，可以发送：

```text
请根据我刚才提交的资料继续第3步。结合具体场景、体感和室内外环境，生成三套 Jennie Styling 视觉转译方案；寒冷时拆分途中外层和目的地造型。
```
