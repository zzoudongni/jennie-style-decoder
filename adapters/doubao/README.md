# 豆包“应用生成”版

## 用户只需 3 步

1. 下载 `jennie-style-decoder-doubao-app.zip`。
2. 在豆包中选择“应用生成”技能并上传整个 ZIP。
3. 发送：`请完整读取压缩包并直接交付 assets/JENNIE_STYLE_DECODER_APP.html，不要从零重写。保留全部 53 张图、完整问卷、动态去重选图，以及第 3 步所有个性化建议模块；严格按 SKILL.md 和 APP_BUILD_SPEC.md 验收。`

无需再单独上传图片、JSON 或代码。

## 当前公开测试版

- 52 条造型研究记录。
- 53 张内嵌低分辨率 WebP 分析参考图。
- 覆盖 45 个不同造型组。
- 单页按 `lookId` 和 `assetId` 双重去重，并跨轮转换。
- 31 张有精确原帖来源，17 张有对应造型记录来源，5 张来源待补充。

## 测试验收

- 首页应显示 6 张不同造型图。
- “换一批参考”应更换组合，不能反复只出现 5 张固定图。
- 个性化结果应有 3 套公式、每套 2 张参考，同页不重复。
- “常穿材质”和“想增加材质”应各有相同的 11 个选项；“当前风格”和“目标风格”应各有相同的 9 个选项。
- 结果页应显示从当前风格到目标风格的迁移方向。
- 每套公式应有 Jennie 逻辑、为你调整、强度，以及站立、坐下、走路、抬手四项试穿检查。
- 公式之后应有主色层级、配饰结构、妆发态度、季节与室内外切换、材质桥接、衣橱升级、购买建议和 7 天审美练习。
- 衣橱升级应优先重组已有单品；购买建议应按 P1–P3 排序，并说明用途和购买前试穿检查。
- 链接标签应区分“原始发布”“造型记录来源”与“来源待补充”。
